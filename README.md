# Spark and Sketch website

Website for Spark and Sketch, a nonprofit that teaches elementary-age kids STEM through art.

## What's here
- `index.html` — the whole site in one page: lessons with games, the cast, the book, events and the shop.
- `assets/character-sketches.jpg` — original character concept sketches.

## Lessons so far
1. **Mirror Magic** (Spider) — symmetry. Game: paint the mirror half of a picture (3 levels).
2. **Honeycomb Hunt** (Bee) — tessellation and 360° angles. Game: tile shapes around a point, then decide which shapes tile.

Each lesson has a video placeholder, a 3-step lesson, an at-home art project, and a game.
